Veterinary AI

What it does

  • Hereditary screening

    Screens a horse or camel genome for the known variants of consequence for the breed, from one sample.

  • Stud and bloodline analysis

    Confirms parentage and maps relatedness across a stud or a bloodline.

  • Performance and welfare

    Assesses trait-associated variants from genomic evidence, each reported with the evidence behind it.

Also: cross-species mapping, breeding support.

Veterinary AI

How it works

Four steps, one run. Nothing is re-uploaded between them and nothing leaves the platform.

Reads in

Sequencing reads (FASTQ) for each animal, one sample per horse or camel.

Map

Reads are mapped to the species' own reference genome, not a human proxy.

Screen

Variants that matter for that species and breed are screened.

Report

Findings are written for the treating vet, with the evidence behind each one.

You need: sequencing reads (FASTQ) for the animal. You get: a report for the treating vet with hereditary, parentage or performance findings and their sources.

Tests by species

Horse and camel.

Four tests for each species. None runs online yet; each is arranged with the Flopexa team.

Horse

  • Whole genome — the full genome, mapped to the horse reference genome, not a human one.
  • Parentage — sire and dam confirmed from a single sample.
  • Hereditary disease panel — known variants of consequence for the breed.
  • Performance markers — trait-associated variants assessed from genomic evidence.
See the horse tests

Camel

  • Whole genome — the full genome, mapped to the camel reference genome.
  • Parentage — lineage confirmed from a single sample.
  • Hereditary disease panel — inherited risk screened from one sample.
  • Racing markers — trait-associated variants assessed from genomic evidence.
See the camel tests

Scope

Built for: equine and camel vets, racing stables, stud farms and breeders.

Not for: human samples; for those, see the human tests.
